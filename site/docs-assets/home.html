Low-poly worlds
in a few words.

PartScript is a small language for building PSX-style 3D models: props, rooms, ruins, whole buildings and the hills they stand on. A few words a line, a few dozen lines a scene, compiled to .glb in pure Python. No Blender needed.

A prop is a few lines

Name a shape and put things on it. Rows pack books of drawn sizes tight; stacks pile papers up; nothing is added up by hand. Every copy draws its own size and colour, and the same file always builds the same model.

What it can make

Everything here is one of the project's example files, built by PartScript and nothing else.

Places

Ground from noise (terrain), walls knocked apart (break=), things that fall onto what is under them (drop=), moss and ivy over named shapes.

Buildings

A kit of walls, floors and stairs, laid out room by room on a grid, each room furnished by a part that knows its size and doors.

Variety

rand(), pick() and when= make every copy different: no two headstones, books or bones alike.

Libraries

Parts with parameters, imported from other files and called like shapes: furniture.table at=....

Paths and links

Pieces that chain end to end, copies along a line of points, loose ends that join themselves up.

The PSX look

Few triangles, small dithered textures with hard pixels, shading baked into the corners of faces.

Use it

From the command line, from Python, or embedded in a game with your own materials and textures. The output is plain glTF: Godot, Unity, Blender, three.js.

pip install partscript

partscript check props/         # instant: mistakes and triangle counts
partscript build props/ -o out/ # every prop as out/<id>.glb
partscript fmt props/a.parts -w # tidy a file
partscript ref                  # the whole language, one page
from partscript import Project

project = Project.from_paths(["props/"])
print(project.check()["errors"])
built = project.build("street_lamp")
open("street_lamp.glb", "wb").write(built.glb)
